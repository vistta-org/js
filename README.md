VisionJS is a Preact/Web Component Integration Framework with the objective of simplifying web development.

## Installation

This is a Node.js module available through this gitlab instance private npm registry. Node.js and npm are required.

On you project folder create a `.npmrc` file with the following content:

```
@vision:registry=https://git.visionos.pt/api/v4/packages/npm/
//git.visionos.pt/api/v4/packages/npm/:_authToken=glpat-mypmHyyJumsV6dkVP4n7
//git.visionos.pt/api/v4/projects/35/packages/npm/:_authToken=glpat-mypmHyyJumsV6dkVP4n7
```

After that you can install the module

```console
npm i @vision/visionjs
```
